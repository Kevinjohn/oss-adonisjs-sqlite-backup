# Capability coverage

Inventory covers Ace commands (`db:backup` and `db:upgrade`), public service and standalone functions, configuration, provider setup, filesystem and database operations, examples, tests and README limitations.

| Story                                                                   | Action                                                                                                       | Access               | Status     | Test scenarios                                    |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | -------------------- | ---------- | ------------------------------------------------- |
| [US-SETUP-01](setup/us-setup-01-configure-backups.md)                   | Configure Lucid source, private root, keep count, lock timeout and WAL requirement                           | Application operator | Operator   | [configure](../tests/configure.spec.ts)           |
| [US-OP-01](create-bundle/us-op-01-create-bundle.md)                     | Copy live SQLite source, check database and migration journal, publish READY last                            | Host operator        | Operator   | [create](../tests/create.spec.ts)                 |
| [US-OP-02](list-bundles/us-op-02-list-bundles.md)                       | List READY bundle names oldest first                                                                         | Host operator        | Operator   | [app](../tests/app.spec.ts)                       |
| [US-OP-03](verify-bundle/us-op-03-verify-bundle.md)                     | Verify manifest, size, SHA-256, integrity, foreign keys and migration metadata                               | Host operator        | Operator   | [verify_restore](../tests/verify_restore.spec.ts) |
| [US-OP-04](prepare-restore/us-op-04-prepare-restore.md)                 | Exclusively stage and verify a copy; leave live database switching to operator                               | Host operator        | Operator   | [durability](../tests/durability.spec.ts)         |
| [US-OP-05](prune-bundles/us-op-05-prune-bundles.md)                     | Retain newest READY bundles and remove older/unfinished matching directories                                 | Host operator        | Operator   | [prune](../tests/prune.spec.ts)                   |
| [US-OP-06](upgrade-database/us-op-06-upgrade-database.md)               | Snapshot a non-empty on-disk database to `pre-migration` or `<db>.backups`, then run `migration:run --force` | Host operator        | Operator   | [upgrade](../tests/upgrade.spec.ts)               |
| [US-OP-07](operator-guards/us-op-07-stopped-server-operator-command.md) | Refuse without stopped-server confirmation, take an EXCLUSIVE lock and attempt pool close on every outcome   | Host operator        | Operator   | [operator](../tests/operator.spec.ts)             |
| [US-INT-01](integration/us-int-01-programmatic-backups.md)              | Use the service or standalone API, own or borrow the source, consume recovery results                        | Host developer       | Public API | [Adoption](../tests/adoption.spec.ts)             |
| [US-INT-02](integration/us-int-02-archive-lock.md)                      | Coordinate archive writers and handle lock release failures                                                  | Host developer       | Public API | [Lock](../tests/lock.spec.ts)                     |

Ace rejects unknown actions and flags used with the wrong action. Only verify and restore preparation take a bundle name, only restore preparation takes a target, only prune takes a keep count, and only list, verify and restore preparation accept a directory override. [Ace dispatch](../commands/db_backup.ts)

The [package exports](../index.ts) also expose the path and durability helpers, error classes and types. The [source map](REFERENCE.md) links their consuming operations. The [packed consumer fixture](../bin/packed_consumer_fixture.mjs) exercises package integration, and the [crash suite](../tests/crash.spec.ts) covers interrupted archive operations.
